# 3. NON-NEGOTIABLE SCIENTIFIC INTERPRETATION

The supplied project documents impose several truth boundaries that must control this audit.

## 3.1 Veyra is a forecast-reliability layer
The project does not replace an issued NWP forecast.
Its core scientific purpose is to estimate whether an already-issued forecast may fail unusually badly, and to communicate uncertainty, evidence boundaries, and abstention honestly.
Do not reward either repository for turning Veyra into a generic weather forecaster.

## 3.2 Public-proxy vs NCMRWF/NEPS
Treat the current project as a public-proxy research prototype unless real paired NCMRWF/NEPS forecast history, metadata, verification truth, permission, and reproducible evaluation are actually present.

Do not award scientific credit for architecture diagrams, variable names, or README language that merely mention:
- NCMRWF,
- NEPS,
- IMD,
- DWR,
- INSAT,
- ECMWF,
- or other systems.

Verify real access and real use separately.

## 3.3 V3 incumbent rule
The frozen V3 is the incumbent until a challenger proves incremental value under the same:
- target definition,
- reference definition,
- temporal protocol,
- leakage rules,
- evaluation contract,
- calibration criteria,
- subgroup analysis,
- uncertainty/bootstrap procedure,
- prediction interval coverage,
- ensemble-member dispersion,
- provider disagreement,
- OOD/novelty,
- confidence heuristic,
- scientific certification.

Do not give a challenger production-science credit simply because it has a more advanced architecture.

## 3.4 No future information
At issue time `t0`, prediction features must use only information available at or before `t0`.

Audit for leakage from:
- future observations,
- future reanalysis,
- future forecast error,
- future bust labels,
- post-valid-time data,
- target-derived features,
- verifying radar/satellite frames,
- or historical retrieval that accidentally includes future periods.

## 3.5 Hazard is not bust
A cyclone, heavy-rain event, heatwave, large ensemble spread, OOD state, or provider disagreement is not automatically a forecast bust.
Hazard-specific models must estimate forecast failure conditional on the hazard/regime, not confuse hazard occurrence probability with forecast unreliability.

## 3.6 Keep uncertainty concepts separate
Do not reward semantic conflation between:
- calibrated P(BUST),
- hazard probability,
- continuous forecast error,
- prediction interval coverage,
- ensemble-member dispersion,
- provider disagreement,
- OOD/novelty,
- confidence heuristic,
- scientific certification.

## 3.7 Missing target rule from the 500-test suite
The 500-test master suite says the final repository is authoritative for what exists.
If a named capability is absent, classify it as `N/A — uncovered/missing`.
Do not invent equivalent functionality.
